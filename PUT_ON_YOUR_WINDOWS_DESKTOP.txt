HOW TO PUT AUTOMATE AI ON YOUR WINDOWS DESKTOP
==============================================

What you saw earlier was the Cloud Agent remote Linux desktop — NOT this
Windows PC. The app must be installed ONCE on your Windows computer.

IF YOU ALREADY INSTALLED IT — UPDATE THE FILES
----------------------------------------------
1. Open your existing Automate AI project folder
2. Double-click:  UPDATE_ON_YOUR_WINDOWS_PC.bat
3. Wait until it finishes — it pulls the latest code onto THIS PC
4. The app restarts with file/folder open + fixed UI


FASTEST WAY (ZIP download — first install)
------------------------------------------
1. Open Chrome and go to:
   https://github.com/muneeb-267/desktop-automation-ai/archive/refs/heads/cursor/desktop-automation-ai-a8ac.zip

2. Extract the ZIP (right-click → Extract All…) to somewhere easy, e.g.:
   Desktop\desktop-automation-ai

3. Open that folder and DOUBLE-CLICK:
   INSTALL_ON_YOUR_WINDOWS_PC.bat

4. When install finishes, if you do NOT see an icon, DOUBLE-CLICK:
   CREATE_DESKTOP_ICON.bat
   (This only creates the Desktop icon — no reinstall.)

5. You should see on Desktop:
   Automate AI
   or Automate AI.bat
   Press F5 to refresh the Desktop if needed.

6. Double-click it → Sign Up Now with YOUR username/password.


IF THE ICON IS STILL MISSING
----------------------------
1. Open the extracted project folder in File Explorer
2. Double-click:  Run Automate AI.bat
   (this starts the app even without a Desktop icon)
3. Then also double-click:  CREATE_DESKTOP_ICON.bat
4. Press F5 on the Desktop


USING GITHUB DESKTOP (you already have it)
------------------------------------------
1. Open GitHub Desktop
2. File → Clone repository → URL:
   https://github.com/muneeb-267/desktop-automation-ai.git
3. After clone: Repository → Show in Explorer
4. Checkout branch: cursor/desktop-automation-ai-a8ac
5. Double-click INSTALL_ON_YOUR_WINDOWS_PC.bat
6. If no icon: double-click CREATE_DESKTOP_ICON.bat


NEED PYTHON?
------------
If the installer says Python is missing:
1. https://www.python.org/downloads/
2. Tick "Add python.exe to PATH"
3. Install, then run INSTALL_ON_YOUR_WINDOWS_PC.bat again


OPTIONAL (better OCR on Windows)
--------------------------------
Install Tesseract OCR:
https://github.com/UB-Mannheim/tesseract/wiki


LOGIN
-----
There is NO demo account.
Use Sign Up Now with your own email/username and password.


FRIEND'S PC / INSTALL ERRORS (yaml, PyAudio)
--------------------------------------------
If the black window shows:
  Failed to build PyAudio
  ModuleNotFoundError: No module named 'yaml'

that means the first install stopped too early. Fix:

1. Close Automate AI if it is open
2. In the SAME extracted folder, double-click:
     INSTALL_ON_YOUR_WINDOWS_PC.bat
   (safe to run again — it finishes the missing packages)

OR download a fresh ZIP of branch cursor/desktop-automation-ai-a8ac
and run INSTALL_ON_YOUR_WINDOWS_PC.bat from the new folder.

PyAudio failing is OK. Voice uses Chrome, not PyAudio.
The app only fails if yaml / PyQt5 are missing — the installer now
installs those first.
